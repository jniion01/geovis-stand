# Arctic GeoVis · стенд модуля «Геомеханика»

Интерактивный стенд разметки и документирования ящика кернов: геология и геомеханика, сценарии 0–9, NewDoc, отчёт А4, выгрузка Word / XLSX / CSV (ГГИС).

**Открыть стенд:** https://jniion01.github.io/geovis-stand/

- Кнопка **«Сценарии 0–9»** в шапке — пошаговый проход с подсказками; «Показать» выполняет шаг сам.
- **«Начать сначала»** — вернуть исходные данные.
- Правки живут только в открытой вкладке: после перезагрузки страницы стенд снова в исходном виде.
- Вопросы и ответы по ТЗ со скриншотами — [Геомеханика_вопросы_и_ответы.pdf](./Геомеханика_вопросы_и_ответы.pdf).

Весь стенд — один файл `index.html`: шрифты, фото керна и данные встроены, сторонние серверы не нужны.
